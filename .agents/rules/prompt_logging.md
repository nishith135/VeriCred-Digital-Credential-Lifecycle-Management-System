# Rule: Mandatory AI Prompt Logging and Compliance

## Description
Every AI agent operating in this workspace must maintain `docs/AI_PROMPT_LOG.md` with complete, verifiable entries for every user prompt, including exact wording, files modified, test evidence, and user review status.

## Non-Negotiable Instructions
1. Before finishing any task or milestone, verify that `docs/AI_PROMPT_LOG.md` contains an accurate entry for the current prompt.
2. Record exact prompt text without paraphrasing or fabrication.
3. Link major decisions to `docs/DECISIONS.md` and test results to `docs/TEST_EVIDENCE.md`.
4. Never commit or log secrets, API keys, or private tokens.
5. Do not claim tests passed or features work without executing them and recording the actual output.
